description: "Reject a deal registration with a reason"
---

Read CLAUDE.md. Run `npm run partners -- reject-registration --json` with the flags the operator gave (--registration=... --reason=... --actor=...).

Present the result as a short table with the numbers that matter. An empty list means no matching records, not that everything is fine.

The reason goes to the partner, so write it plainly. Offer `/draft-registration-reply` after.

Never send anything. Drafts go to drafts/ for a person to send. Never invent a partner, an amount or a date.
